# Project Nhập Thông Tin Cá Nhân (C)

Đây là một chương trình C đơn giản cho phép người dùng nhập và hiển thị thông tin cá nhân.  
Project được viết bằng Visual Studio và sử dụng ngôn ngữ lập trình C cơ bản.

## 🧩 Chức năng chính
- Nhập họ tên
- Nhập tuổi
- Nhập địa chỉ hoặc thông tin khác
- Hiển thị lại toàn bộ thông tin đã nhập
- Kiểm tra dữ liệu đầu vào đơn giản

## 🚀 Cách chạy chương trình
1. Mở project bằng **Visual Studio**
2. Nhấn **Build** để biên dịch chương trình
3. Nhấn **Run** để chạy
4. Nhập thông tin theo hướng dẫn trên màn hình

## 📁 Cấu trúc project
- `Project1.slnx` — file solution của Visual Studio  
- `Project1/` — chứa file `.vcxproj` và mã nguồn C  
- `main.c` hoặc các file `.c` khác — nơi chứa code chính

## 🛠 Công nghệ sử dụng
- Ngôn ngữ: **C**
- IDE: **Visual Studio 2022**
- Compiler: MSVC
